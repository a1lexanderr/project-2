## Управление таблицами
База данных поддерживает базовые операции DDL:
- `create_table users name:str age:int` — создает таблицу (столбец ID генерируется автоматически)
- `list_tables` — список таблиц
- `drop_table users` — удаляет таблицу

## CRUD-операции
База данных поддерживает полноценное управление данными внутри таблиц:
- insert into <имя_таблицы> values (<значение1>, <значение2>, ...) — создать новую запись.
- select from <имя_таблицы> — прочитать все записи из таблицы.
- select from <имя_таблицы> where <столбец> = <значение> — прочитать записи с фильтрацией.
- update <имя_таблицы> set <столбец1> = <новое_значение> where <столбец_условия> = <значение_условия> — обновить существующую запись.
- delete from <имя_таблицы> where <столбец> = <значение> — удалить запись по условию.
- info <имя_таблицы> — вывести информацию о структуре таблицы и количестве записей.
