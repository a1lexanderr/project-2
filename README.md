# Primitive DB

Проект поддерживает создание таблиц с типизацией данных, полноценные CRUD-операции, а также безопасную обработку ошибок и кэширование запросов.

## Установка и запуск

1. Установите зависимости:
   `uv sync`
2. Запустите базу данных:
   `uv run database`

## Управление таблицами
База данных поддерживает базовые операции DDL:
- `create_table users name:str age:int` — создает таблицу (столбец ID генерируется автоматически)
- `list_tables` — список таблиц
- `drop_table users` — удаляет таблицу

## CRUD-операции
База данных поддерживает полноценное управление данными внутри таблиц:
- insert into <имя_таблицы> values (<значение1>, <значение2>, ...) — создать новую запись.
- select from <имя_таблицы> — прочитать все записи из таблицы.
- select from <имя_таблицы> where <столбец> = <значение> — прочитать записи с фильтрацией.
- update <имя_таблицы> set <столбец1> = <новое_значение> where <столбец_условия> = <значение_условия> — обновить существующую запись.
- delete from <имя_таблицы> where <столбец> = <значение> — удалить запись по условию.
- info <имя_таблицы> — вывести информацию о структуре таблицы и количестве записей.

## Продвинутые возможности (Декораторы и кэширование)
В базу данных интегрированы механизмы оптимизации и безопасности "под капотом":
- **Централизованная обработка ошибок:** Ввод некорректных типов данных или обращение к несуществующим таблицам больше не приводит к аварийному завершению программы. Ошибки перехватываются и выводятся в понятном виде.
- **Подтверждение действий:** Опасные операции, такие как удаление таблиц (`drop_table`) и удаление записей (`delete`), теперь требуют явного подтверждения от пользователя `[y/n]`.
- **Логирование времени:** Операции чтения и записи замеряются, и в консоль выводится точное время их выполнения.
- **Кэширование запросов:** При повторном вызове команды `select` с идентичными условиями, база данных не читает файлы заново, а мгновенно возвращает результат из кэша (используется механизм замыканий).
